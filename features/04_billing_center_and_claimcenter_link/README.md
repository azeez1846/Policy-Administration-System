# Module 04: Billing Center, Audit & ClaimCenter Link

## Overview
Integrates Billing Center 12-Pay/4-Pay/1-Pay installment schedules and ClaimCenter real-time claim loss runs, paid claims, and open reserves.

## Files Included
- `BillingCenterController.java`: Spring REST Controller (`/api/billing/installment-schedule`).
- `ClaimCenterController.java`: Spring REST Controller (`/api/claims/loss-history`).
- `BillingCenterScreen.js`: Installment schedule ledger & payment processor UI.
- `ClaimsScreen.js`: ClaimCenter loss history and reserve tracking UI.
