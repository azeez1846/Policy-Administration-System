# Module 02: No-Code Product Model Designer & Gosu Rule Studio

## Overview
This feature provides a visual No-Code Product Model configurator to create lines of business, coverage terms, deductibles, and limits, along with an interactive web editor for Gosu Business Rules with live syntax highlighting and execution logs.

## Files Included
- `GosuStudioController.java`: Spring Boot REST Controller (`/api/gosu/execute`, `/api/gosu/rules`).
- `ProductDesignerScreen.js`: No-Code Product Model Designer UI component.
- `GosuRuleStudioScreen.js`: Interactive Gosu Rule Studio & compiler console UI component.

## Key Capabilities
- Drag-and-drop Product Model LOB configurator.
- Gosu Rule Editor with sample templates (*High Building Limit Referral*, *Pre-1980 Structural Age Check*, *FEIN Tax ID Format Validation*).
