# Module 08: Underwriting Activity Task & Note Management Engine

## Overview
Full Guidewire `Activity` task management system allowing underwriters to create, assign, and complete follow-up tasks, set priority chips (*Urgent*, *High*, *Medium*), and log time-stamped underwriting notes.

## Files Included
- `ActivityController.java`: REST Controller (`/api/activities`, `/api/activities/notes`).
- `ActivityTaskScreen.js`: Task manager view and internal notes feed UI component.
