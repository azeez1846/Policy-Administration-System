# Module 07: Guidewire Assist AI Chatbot Widget

## Overview
A persistent floating AI chatbot docked at the bottom-right corner of PolicyCenter. Underwriters can type natural language questions regarding accounts, submissions, rating worksheets, and Gosu rules.

## Files Included
- `AIAssistController.java`: REST Controller (`/api/ai-assist/chat`).
- `GuidewireAIChatWidget.js`: Floating AI chat button & window component docked at bottom-right corner.
