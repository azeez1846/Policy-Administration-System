# Module 05: Producer Quick-Quote & Insured Self-Service Portals

## Overview
Provides a 60-second instant Producer Quick-Quote portal for insurance agents and a customer self-service portal for downloading policy declarations pages and Certificates of Insurance (ACORD 25).

## Files Included
- `PortalController.java`: REST Controller (`/api/portal/quick-quote`, `/api/portal/coi`).
- `ProducerPortalScreen.js`: Agent 60-second quick quote UI component.
- `PolicyholderPortalScreen.js`: Insured customer self-service portal UI component.
