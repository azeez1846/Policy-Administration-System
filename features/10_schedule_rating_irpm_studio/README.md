# Module 10: Schedule Rating Modification (IRPM) & Factor Override Studio

## Overview
Interactive schedule rating matrix allowing underwriters to apply Individual Risk Premium Modification (IRPM) credits or debits (-25% to +25%) with automatic premium recalculation and audit logging.

## Files Included
- `IRPMController.java`: REST Controller (`/api/rating/irpm`).
- `IRPMScreen.js`: Schedule rating matrix and IRPM factor override UI component.
