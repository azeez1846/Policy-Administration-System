# Module 06: ACORD 125/140 & Policy Binder Document Studio

## Overview
Generates formatted printable HTML/PDF document templates for ACORD 125 (Commercial Insurance Application), ACORD 140 (Commercial Property Schedule), ACORD 25 (COI), and Commercial Policy Binders.

## Files Included
- `ACORDDocumentController.java`: REST Controller (`/api/documents/acord125`, `/api/documents/acord140`).
- `ACORDDocumentScreen.js`: Printable preview modal and document library viewer UI component.
